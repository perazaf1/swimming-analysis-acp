# 100m Freestyle Swimming: Profiling & Modelling

Analysis of elite 100m Freestyle performances from World Aquatics Top 200 records (1980-2022) and Olympic Games results (1988-2020), using SVD/PCA and Ridge regression coded directly in `NumPy` and `SciPy`.

The full report is available in [`paper/paper.pdf`](paper/paper.pdf).

## Repository Structure

```text
.
├── data/
│   ├── raw/                  # Raw CSV datasets (top_perf_categories.csv, Results_1912to2020.csv)
│   └── processed/            # Cleaned tables and multi-event swimmer matrix (Phase 1 output)
├── paper/
│   ├── figures/              # Plots generated by Phases 2 and 3
│   ├── paper.tex             # LaTeX source of the report
│   └── paper.pdf             # Compiled report
└── src/sports_analytics_l3/
    ├── data_cleaning.py      # Phase 1: time/date parsing, alias resolution, processed CSVs
    ├── spectral_pca.py       # Phase 2: gender standardization, reduced SVD/PCA, rank-2 completion
    └── modelling.py          # Phase 3: collinearity (VIF, cond), OLS/MP/Ridge, LOO CV, Fisher 95% CIs
```

## Data Sources

- **World Aquatics All-Time Top 200 (1980-2022):** [`romaniandatatribe/swimming-top-in-the-world-in-each-category`](https://www.kaggle.com/datasets/romaniandatatribe/swimming-top-in-the-world-in-each-category) (Kaggle)
- **Olympic Swimming Results (1912-2020):** [`datasciencedonut/olympic-swimming-1912-to-2020`](https://www.kaggle.com/datasets/datasciencedonut/olympic-swimming-1912-to-2020) (Kaggle)

## Run

Requires Python 3.12+ and [uv](https://docs.astral.sh/uv/). Run the full pipeline in one command, or execute the three phases in order (each phase reads the outputs of the previous one):

```bash
uv sync

# Option A: run all 3 phases sequentially
uv run sports-analytics-l3

# Option B: run each phase script with its built-in test suite
uv run python src/sports_analytics_l3/data_cleaning.py
uv run python src/sports_analytics_l3/spectral_pca.py
uv run python src/sports_analytics_l3/modelling.py
```

To recompile the LaTeX report:

```bash
cd paper && pdflatex paper.tex && pdflatex paper.tex && latexmk -c paper.tex
```
